# Security policy

## Supported versions

Security fixes are currently applied to the latest release on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on the repository's **Security** tab. Include a minimal reproduction, affected version, impact, and any suggested mitigation.

Repo Metro processes untrusted Git metadata and writes an HTML document, so injection, path handling, and accidental data disclosure reports are especially valuable.
